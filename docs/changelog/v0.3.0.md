# Changelog: v0.2.0 → v0.3.0

## Summary

v0.3.0 is a major architectural upgrade that introduces a **device-agnostic** compute pipeline via KernelAbstractions.jl, enabling CFFT/ICFFT execution on both CPU and NVIDIA GPU. It also adds R2C FFT transforms (`rcfft`/`ircfft`), a star-orbit mapping API (`SubgridStarMap`), stress-computation helpers, and significant performance optimizations across several critical code paths.

---

## ✨ New Features

### Device-Agnostic Architecture

- **Complete rewrite of the core compute pipeline** from CPU-only to device-agnostic via KernelAbstractions.jl:
  - New `src/types.jl` (275 lines): Fully parametric plan types (`ForwardPlan`, `BackwardPlan`, `CenteredForwardPlan`, `CenteredBackwardPlan`, `RealForwardPlan`, `RealBackwardPlan`). All type parameters are inferred from buffer/plan arguments at construction time.
  - New `src/kernels.jl` (413 lines): KernelAbstractions `@kernel` functions for forward/backward reconstruction, Pmmm separable fast path, centering fold/unfold, R2C data copy, etc.
  - New `src/planning.jl` (1,178 lines): Device-agnostic plan builders (`plan_forward`, `plan_backward`, `plan_centered_forward`, `plan_centered_backward`, `plan_real_forward`, `plan_real_backward`).
  - New `src/execute.jl` (750 lines): Execute-time pipeline orchestration. CPU path uses optimized `@inbounds @simd` scalar loops; GPU path dispatches KA kernels.
- **Legacy modules archived**: `src/krfft.jl`, `src/cfft_plan.jl`, `src/execution.jl`, `src/q_fused_krfft.jl`, `src/diffusion_solver.jl`, and others moved to `src/archived/`.

### CUDA GPU Support

- **Weak-dependency extension** via `ext/CUDAExt.jl`: optional CUDA.jl support without imposing a hard dependency.
  - Automatic `CuArray` detection switches to `CUDABackend()`.
  - Both General (M2) and Centered (M7) paths are GPU-accelerated.
- **GPU optimizations**: unnecessary `sync` calls removed, batched CuFFT enabled, fused-kernel experiment explored.
- **New dependencies**: `Adapt.jl` v4 (hard), `CUDA.jl` v5 (weak dep).

### R2C FFT Transforms (rcfft / ircfft)

- **New `rcfft!` / `ircfft!` transforms**: Real-to-complex FFT path using `rfft`/`irfft`, exploiting real-valued symmetry to further reduce computation and memory.
- **New plan types**: `RCFFTPlan`, `IRCFFTPlan`, `GeneralRCFFTPairPlan`.
- **New API functions**: `plan_rcfft`, `plan_ircfft`, `plan_rcfft_pair`, `rcfft!`, `ircfft!`.
- Supports all 230 space groups (centered lattices handled via the General route).

### Star Mapping API (SubgridStarMap)

- **New `SubgridStarMap` type**: mapping between subgrid linear indices and symmetry-orbit (star) indices, stored in CSR format for efficient bidirectional conversion.
  - Fields: `sub_to_star`, `star_offsets`, `star_sub_list`, `sub_degeneracy`, `n_stars`.
- **New functions**:
  - `build_subgrid_star_map(plan)` — Union-Find-based star construction.
  - `expand_stars!(f0, map, compressed)` — expand star representation to full subgrid.
  - `compress_stars!(compressed, map, f0)` — compress subgrid data into star representation.

### Stress Computation Helper

- **New `cfft_kk_orbsum(plan, lattice)`**: computes orbit-weighted $\mathbf{k} \otimes \mathbf{k}$ sums over the spectral ASU, facilitating SCFT stress tensor evaluation.

## 🚀 Performance Optimizations

### `build_subgrid_star_map` — 31× speedup

- **Ia-3d (SG 230) N=128**: 22,157 ms / 8.4 GB → 711 ms / 4.7 MB.
- Module-level Union-Find helpers eliminate closure overhead; pre-allocated buffers remove per-iteration heap allocations.

### `plan_rcfft_pair` — 6× speedup

- **Ia-3d N=64**: 5,526 ms → 946 ms, with additional follow-up optimization.
- Streamlined spectral ASU construction and plan initialization path.

### `calc_spectral_asu` — zero-allocation inner loop

- Rotation matrices pre-extracted as `NTuple{9,Int}` flat tuples for zero-alloc inner loops.
- Pre-allocated worklist buffer replaces dynamically growing arrays.
- Bitwise fast-modulo for power-of-2 grid sizes.
- Direct-op translations pre-extracted as `NTuple{3,Float64}`.

### `recommended_N` — algorithm rewrite

- Replaced static `optimal_L`-based lookup with dynamic `auto_L`-based computation.
- New `_required_N_divisor` function tests multiple candidate N values to determine the minimum divisor per space group.
- Result cache (`_N_DIVISOR_CACHE`) avoids redundant computation.
- Correctly handles complex groups like Ia-3d (requiring N divisible by 8).

## 📖 API Changes

### New Exports

```julia
# R2C FFT
export RCFFTPlan, IRCFFTPlan, GeneralRCFFTPairPlan
export plan_rcfft, plan_ircfft, plan_rcfft_pair
export rcfft!, ircfft!

# Star mapping
export SubgridStarMap, build_subgrid_star_map, expand_stars!, compress_stars!

# Stress computation
export cfft_kk_orbsum
```

### Internal Architecture Changes

- Legacy modules (`KRFFT`, `QFusedKRFFT`, `DiffusionSolver`) are no longer loaded from the main module; moved to `src/archived/`.
- Plan types migrated from concrete types (e.g., `GeneralForwardPlan`) to fully generic parametric types (e.g., `ForwardPlan{T,D,P,VA,AA,VI}`).
- Extensible backend inference via `_infer_backend(::Type{<:AbstractArray})`.
